# Запуск и устройство проекта «Горизонт»

Проект прогнозирует загрузку и среднюю цену проданного номера (ADR) на 14 дней для трёх учебных гостиниц. В рабочем запуске он дополнительно собирает свежие анонсы Москвы и опубликованные тарифы двух реальных гостиниц. Дашборд открывается в браузере и работает через локальный сервер Python.

## Первый запуск на Windows

1. В PyCharm выберите **File → Open** и откройте папку **HotelForecast**, в которой лежат `README.md` и `run-dashboard.cmd`.
2. Внизу откройте **Terminal**. Проверьте, что установлен Python 3.12, командой `py -3.12 --version`. Если Python отсутствует, установите Python 3.12 для Windows. Если PyCharm уже создал окружение, запуск может использовать его напрямую при наличии `.venv\Scripts\python.exe`.
3. Выполните команду ниже. При первом запуске скрипт создаст `.venv` и установит NumPy. Для этой установки обычно нужен интернет.

```powershell
.\run-dashboard.cmd
```

Браузер откроет [дашборд на порту 8765](http://127.0.0.1:8765/). Если вкладка не открылась, скопируйте адрес из терминала. Пока идёт демонстрация, оставьте терминал открытым. Для остановки нажмите **Ctrl+C**. При занятом порту запустите `.\run-dashboard.cmd --port 8766`.

### Запуск зелёной кнопкой PyCharm

После первого запуска выберите `.venv\Scripts\python.exe` в **Settings → Python → Interpreter**. Затем в **Run → Edit Configurations → + → Python** создайте конфигурацию.

| Поле | Значение |
| --- | --- |
| Name | `HotelForecast` |
| Run target | Выберите **Module name** и введите `hotel.cli` |
| Parameters | `demo --open-browser` |
| Python interpreter | Интерпретатор проекта из `.venv` |
| Working directory | Папка `HotelForecast`, выберите её через значок папки |
| Interpreter options | `-X utf8` |

Поле **Interpreter options** можно включить через **Modify options**. Для запуска с архивом сделайте копию конфигурации и задайте параметры `demo --archive --open-browser`. [Интерпретатор PyCharm](https://www.jetbrains.com/help/pycharm/configuring-python-interpreter.html), [конфигурации запуска](https://www.jetbrains.com/help/pycharm/run-debug-configuration.html).

Команды для ручной подготовки окружения, если хотите управлять зависимостями самостоятельно.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -X utf8 -m hotel.cli demo --open-browser
```

## Что происходит при запуске

1. Python фиксирует дату расчёта по Москве. Загружает недостающие дни учебного PMS и проверяет вместимость, число проданных номеров и выручку. Загрузка равна 100 × проданные номеро-ночи / доступные номеро-ночи. ADR равна выручке от проживания / проданные номеро-ночи.
2. Загружает локальный архив и делает запрос к KudaGo. При ошибке или отсутствии подходящих анонсов пробует «Мосбилет». Если оба источника недоступны, выбирает локальный архив. В архиве есть только проверенные даты. Когда они выходят из горизонта, в нём может не оказаться событий. «Мосбилет» даёт выборку анонсов. Для событий с несколькими показами берётся первая указанная дата без заполнения промежутков. [KudaGo](https://docs.kudago.com/api/), [Мосбилет](https://bilet.mos.ru/).
3. Отдельно загружает опубликованные прайсы «Таёжного» и «Аструса». В разделе «Публичные цены гостиниц» видны категория, цена в рублях за сутки для двух гостей, условия, период по прайсу и время успешной проверки. При сбое используется последняя успешно проверенная версия или снимок из репозитория. Эти цены справочные и зависят от условий. Доступность номера и итоговую цену на конкретную ночь определяет форма бронирования. [Прайс «Таёжного»](https://www.tbhotel.ru/prices/), [прайс «Аструса»](https://astrus.bronhotel.ru/).
4. Рассчитывает признаки по данным, известным к дате выпуска. Для загрузки применяется Хьюбер на днях 1–7 и Ridge на днях 8–14. Для ADR используется Ridge. Свежая афиша меняет сценарий будущего прогноза. Опубликованные цены остаются рыночным ориентиром в отдельном разделе.
5. Записывает HTML и JSON в `build/`, открывает браузер и обслуживает страницу на `127.0.0.1`. Обновление вкладки показывает текущий расчёт. Для повторного запроса к внешним источникам запустите проект заново или выполните `python -X utf8 -m hotel.cli build --public` из окружения проекта.

Каждая попытка онлайн-загрузки попадает в журнал. Если содержимое ответа совпадает с сохранённым, база повторно использует снимок и обновляет время последней успешной проверки. Если тарифы меняются, а затем возвращаются к предыдущим значениям, при сбое будет показана последняя успешно полученная версия.

## Как проверяется точность

Внутренняя проверка использует отложенные периоды симуляции. Она показывает, корректно ли устроен эксперимент и улучшают ли модели сезонный ориентир при заданных в генераторе эффектах. Например, на подтверждающем периоде MAE загрузки улучшилась с 3,40 до 3,34 процентного пункта.

Дополнительная проверка использует исходные файлы H1 и H2 статьи Hotel Booking Demand. Для каждого дня приблизительная ADR восстановлена по завершённым платным бронированиям. Средний тариф бронирования применяется к каждой ночи проживания. Значение считается известным после выезда всех включённых в него гостей. Ridge и сезонная медиана получают одинаковую историю, известную к выпуску. У Ridge только история ADR и календарь. Для каждого отеля сделано восемь последовательных прогнозов по 14 дней на период с 10.04.2017 по 30.07.2017. [Статья и данные](https://doi.org/10.1016/j.dib.2018.11.126).

| Отель | MAE сезонной медианы | MAE Ridge |
| --- | ---: | ---: |
| Курортный, Алгарве | 28,98 | 23,12 |
| Городской, Лиссабон | 10,38 | 9,24 |

Ошибки приведены в денежных единицах набора. Для проверки текущего московского прогноза нужны суточные выгрузки PMS конкретных гостиниц с доступными и проданными номеро-ночами и выручкой. Тогда можно провести последовательные 14-дневные проверки с той же базовой моделью и историческими снимками афиши, сравнить MAE и RMSE по каждой гостинице и неделе горизонта. Влияние афиши проверяется сравнением вариантов с её признаками и без них на одинаковых датах.

Для воспроизведения внешней проверки из PyCharm Terminal выполните команду ниже. Она скачает оригинальный архив статьи и напечатает результат. При уже скачанном архиве добавьте `--source путь_к_mmc2.zip`.

```powershell
.\.venv\Scripts\python.exe -X utf8 -m tools.validate_real_adr
```
